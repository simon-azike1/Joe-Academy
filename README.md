# Joe Academy 🎓

A full-stack Learning Management System (LMS) built with the MERN stack. 
Joe Academy allows students to browse, purchase, and stream courses, 
while lecturers can manage content and track enrollments.

## Features

- 🔐 JWT Authentication (student & lecturer roles)
- 🎬 Video lecture streaming via Bunny.net CDN
- 💳 Dual payment system — Stripe (online) & WhatsApp (manual)
- 📱 WhatsApp order notifications to lecturers via Twilio
- 📊 Student progress tracking with credit rewards
- 🔒 Sequential lecture unlocking system
- 🖼️ Image hosting via Cloudinary
- 📧 Admin panel for managing courses, lectures & enrollments

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React, Tailwind CSS, Framer Motion |
| Backend | Node.js, Express.js |
| Database | MongoDB Atlas |
| Auth | JWT |
| Payments | Stripe |
| Video | Bunny.net Stream |
| Images | Cloudinary |
| Notifications | Twilio WhatsApp API |
| Deployment | Vercel (frontend), Render (backend) |
